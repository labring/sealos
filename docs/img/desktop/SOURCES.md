# Desktop README media

Captured from the live HTML/CSS product demonstrations at https://sealos.io/ on 2026-11-18. Product positioning also references https://sealos.cn/downloads.

- `desktop-deploy.gif`: deployment conversation and architecture, captured at 2× device pixel ratio; 1720 × 1304 pixels, 80 frames at 5 fps, 256-color palette without dithering, looping. The surrounding sidebar and decorative background are excluded to keep UI text readable at README width.
- `local-deploy.png`: local deployment and live preview, 3× device pixel ratio, lossless PNG.
- `service-overview.png`: database overview, 3× device pixel ratio, lossless PNG.
- `ops-logs.png`: project log viewer, 3× device pixel ratio, lossless PNG.
- `topology.png`: completed app/PostgreSQL/Redis topology, 3× device pixel ratio, lossless PNG.

Screenshots are rendered from the original DOM, not upscaled from the earlier WebP files. Decorative framing is excluded where possible; ancestor overflow clipping is removed for the screenshot without changing UI content. The same English-language product demos appear in both READMEs, with the Chinese README labeling their origin.

Images link to their full-resolution repository files. The separate homepage link opens the interactive JavaScript version. These are website product demonstrations, not deployments executed for this repository.
